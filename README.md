# Faytek Starter

> Template officiel FaytekDev — basé sur l'architecture BuyFlow (tsSiens)

## Démarrage Rapide

### Backend
```bash
cd backend
npm install
cp .env.example .env   # Configurer les variables
npm run dev            # http://localhost:5000
```

### Frontend
```bash
cd frontend
npm install
cp .env.example .env   # Configurer VITE_HOST_API_KEY
npm run dev            # http://localhost:5173
```
